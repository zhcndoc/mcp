规范增强提案（SEP）是提议修改 Model Context Protocol 的主要机制。每份 SEP 都会为拟议功能提供简明的技术规范和设计理由。

每份 SEP 都可通过编号访问，路径格式为 `/seps/<number>`（例如 [/seps/1850](/seps/1850)）。

</Card>
