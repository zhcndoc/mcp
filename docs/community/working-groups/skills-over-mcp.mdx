## 工作组类型

**工作组**

## 使命宣言

Skills Over MCP 工作组定义了“agent skills”——用于 agent 工作流的丰富、结构化指令——如何通过 MCP 被发现、分发和消费。主机应用中对原生 skills 的支持表明需求强烈，而该工作组源自对 [SEP-2076 — Agent Skills as a First-Class MCP Primitive](https://github.com/modelcontextprotocol/modelcontextprotocol/pull/2076) 的讨论，该讨论提出了一个尚未解决的问题：现有的 MCP 原语是否足够，还是需要标准化哪些约定。该 WG 会产出规范扩展、参考实现和协调性产物，因为这些解决方案会同时涉及协议规范、注册表 schema、SDK 实现以及客户端行为。

[SEP-2640 — Skills Extension](/seps/2640-skills-extension) 已定稿。WG 在 [modelcontextprotocol/ext-skills](https://github.com/modelcontextprotocol/ext-skills) 中维护官方 [Skills 扩展](/extensions/skills/overview)（`io.modelcontextprotocol/skills`）。当前工作重点是实现支持、互操作性以及已发布扩展的演进。

## 范围

### 范围内

- **规范工作**：维护和演进 Skills 扩展，变更记录在[决策日志](https://github.com/modelcontextprotocol/ext-skills/blob/main/docs/decisions.md)中；相关核心协议变更通过 SEP 流程提出
- **参考实现**：展示技能发现和消费模式的 SDK 组件与参考服务器
- **跨领域关注点**：与 Registry WG（技能发现／分发、注册表 schema 变更）、Agents WG（技能激活、服务器元数据消费）和 Primitive Grouping IG（渐进式披露模式）协调，并与外部项目协作，包括 [Agent Skills](https://agentskills.io/) 规范（内容格式和 well-known URI 发现）、FastMCP 和 PydanticAI
- **文档**：涵盖技能编写、发现和消费的规范章节与指南

### 范围外

- **注册表 schema 决策**：schema 的所有权属于 Registry WG；本 WG 提供需求，但不拥有该 schema
- **客户端实现要求**：我们可以记录模式，但不能要求特定的客户端行为
- **插件／bundle 打包**：可安装的 bundle（技能 + 服务器 + 子代理 + 配置作为单一工件）——由使用场景推动，但属于更广泛的打包工作

### 相关工作组

- **Agents WG** — agent 如何消费服务器元数据、技能激活
- **Registry WG** — 技能发现／分发、注册表 schema 变更
- **Primitive Grouping IG** — 渐进式披露模式

### 已完成的里程碑

- [Skills 一致性场景](https://github.com/modelcontextprotocol/conformance/pull/330) 已于 2026 年 9 月 11 日合并。

### 当前工作

在 [ext-skills issues](https://github.com/modelcontextprotocol/ext-skills/issues) 中跟踪提案、实现工作和协调，并链接到实现所在的 SDK 或客户端 issue。
所有者、进度和优先级在该处维护，而不是本章程中。

### 成功标准

- **规范**：已发布基于 Resources 的 Skills 扩展——通过最终版 SEP-2640 实现。
- **实现**：SDK 和主机实现通过适用的一致性场景。
- **互操作性**：独立 MCP 服务器和客户端能够一致地发现和加载技能。
