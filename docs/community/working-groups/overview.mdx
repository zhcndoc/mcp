工作组负责交付具体成果，例如 SEP、扩展和代码。每个工作组都依据章程运作，章程规定其范围、负责人和运作方式。本页列出当前活跃的工作组。[工作组与兴趣组](/community/working-interest-groups)介绍小组的运作方式，以及如何加入或创建小组；[章程模板](/community/charter-template)介绍如何提交章程。
