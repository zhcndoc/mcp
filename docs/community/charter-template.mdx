本页面提供了每个工作组和兴趣小组必须遵循的章程模板，并解释了如何提交章程。该模板已被规范增强提案 (SEP) [SEP-2149](/seps/2149) 采用，并与 [工作组和兴趣组](/community/working-interest-groups) 中的规则一起由流程 SEP 进行更改。每个章程位于 [modelcontextprotocol 存储库](https://github.com/modelcontextprotocol/modelcontextprotocol) 中的 `docs/community/working-groups/<name>.mdx` 或 `docs/community/interest-groups/<name>.mdx`，仅记录小组的使命、范围、领导、成员资格和运营，并且不重述这些适用于每个小组的规则。标记为 **（仅限 WG）** 的部分对于工作组是必需的，对于兴趣组是可选的。要创建群组，请参阅[组建群组](/community/working-interest-groups#forming-a-group)。

<a id="submitting-a-charter" />
## 提交章程

- 该团体必须已经在[组建团体](/community/working-interest-groups#forming-a-group)下得到赞助。
- 将下面的模板复制到章程文件中并替换占位符。删除 `{/* */}` 指导注释或保留其原样：HTML 注释会破坏 MDX 构建，而 `npm run format` 会损坏跨行的 `{/* */}` 注释。
- 运行 `npm run prep`，然后推送。
- 打开一个拉取请求，添加章程文件、`docs/docs.json` 中工作组或兴趣组下的导航条目以及 [当前组](/community/working-interest-groups#current-groups) 下的一行。
- 核心维护者将按照[修改或撤销组](/community/working-interest-groups#amending-or-retiring-a-group) 要求中的概述审核拉取请求。
- 后续更改遵循[修改或退休小组](/community/working-interest-groups#amending-or-retiring-a-group) 并在章程的变更日志中添加一行。
<Note>
  [运输](/community/working-groups/transports) 和
  [安全](/community/interest-groups/security) 是填写的示例，用于
  分别是工作组和兴趣小组。
</Note>
