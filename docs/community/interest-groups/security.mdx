## 组类型

**兴趣组**

<a id="mission-statement" />
## 使命声明

安全兴趣组是 MCP 特定安全主题的第一站。它审查传入的
威胁、安全相关提案和披露问题，然后将经过验证的工作发送给
拥有它的工作组或 [SEP](/community/sep-guidelines)。

<a id="scope" />
## 范围

<a id="in-scope" />
### 范围内

- **分类和路由**：接收在 Discord 或 GitHub 上提出的安全主题并提交
  所属组（Auth IG、传输工作组、注册表工作组、工具注释 IG、SDK 维护者）
- **威胁建模**：开发和维护 MCP 攻击面的共享分层视图
  涵盖准入和身份、调用者治理、运行时行为、拦截和执行，
  和可审计性，为各个提案提供共同的参考框架
- **服务器身份、证明和准入**：建立服务器的要求
  在客户端发送给它之前它所声称的内容，包括签名的断言、信任根、
  以及协议级和注册表级验证之间的界限
- **供应链和出处**：本地执行的服务器二进制文件和包的完整性
  （误植、未固定的依赖项、未签名的工件）以及客户如何验证他们的内容
  产卵
- **运行时漂移和准入后更改**：对工具、模式或行为更改后的处理
  服务器已获得批准，以及此类更改是否是版本控制、重新批准或安全性
  事件
- **可审计性和可观察性**：对工具调用内容的防篡改记录的要求
  进行了合规性和事件审查以及在什么授权下进行的
- **邻近传输的安全性**：秘密处理、进程隔离和未经身份验证的表面
  用于 stdio 和其他 HTTP 授权规范不涉及的非 HTTP 传输的区域
  申请
- **安全最佳实践文档**：创作和审查条目
  [安全最佳实践](/docs/tutorials/security/security_best_practices) 指南，包括
  与 OWASP GenAI 和 CoSAI 等外部机构就 MCP 特定内容进行联络
- **漏洞披露路由**：为有以下情况的记者提供已知的联系点：
  针对 MCP 存储库提交了私人安全咨询，并需要帮助达到正确的要求
  维护者

<a id="out-of-scope" />
### 范围外

- **授权协议机制**：OAuth 流程、作用域、客户端注册和令牌处理属于 [授权 IG](/community/interest-groups/auth) 及其衍生的工作组
- **传输层线缆安全**：TLS、mTLS 和证书处理属于 Transports WG
- **工具注解设计**：注解模型本身属于 [工具注解 IG](/community/interest-groups/tool-annotations)。该组提供安全要求作为输入
- **注册表服务运维**：运行和保护托管的 Registry 服务属于 [Registry WG](/community/working-groups/registry)。该组就来源证明和发布提供威胁输入
- **产品特定的加固指南**：面向单个宿主应用或云平台的逐步配置说明属于这些产品的文档，而非协议工作
- **具有竞争敏感性或非公开的商业信息**，依据 [MCP 反垄断政策](/community/antitrust)

<a id="related-groups" />
### 相关组

- **[Authorization IG](/community/interest-groups/auth)**：令牌混淆、受众不匹配和元数据发现中的 SSRF 位于两个组的交界处
- **[Tool Annotations IG](/community/interest-groups/tool-annotations)**：信任和敏感性注解（[SEP-1913](https://github.com/modelcontextprotocol/modelcontextprotocol/pull/1913)）横跨两个组
- **[Interceptors WG](/community/working-groups/interceptors)**：拦截器是此处提出的运行时安全决策的主要执行点
- **[Server Card WG](/community/working-groups/server-card) / [Registry WG](/community/working-groups/registry)**：服务器身份、来源和发现元数据与接入和供应链问题相交
- **[Transports WG](/community/working-groups/transports)**：stdio 进程隔离和未认证的方法面
- **SDK 维护者**：协调处理 SDK 安全公告和跨 SDK 安全默认设置

## 运作
