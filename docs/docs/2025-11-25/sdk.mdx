## 快速开始

每个 SDK 都提供相同的功能，但遵循其所使用语言的惯用法和最佳实践。所有 SDK 都支持：

- 创建暴露工具、资源和提示的 MCP 服务器
- 构建可连接到任何 MCP 服务器的 MCP 客户端
- 本地和远程传输协议
- 带类型安全的协议兼容性

请访问你所选语言的 SDK 页面，查看安装说明、文档和示例。
