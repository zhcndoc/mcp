[代理技能](https://agentskills.io/home)是一种可移植的指令集，能够为
AI 编码助手提供特定任务的领域知识。对于 MCP 开发，它们会编码设计决策（部署模型、工具模式、认证），
以便你的代理可以询问你的用例并搭建一个适合的服务器。

## 可用技能

有一组 MCP 开发技能可作为
[`mcp-server-dev` 插件](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/mcp-server-dev) 使用。
它提供三种组合技能：

| 技能               | 目的                                                                                                                    |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| `build-mcp-server` | 入口点。分析使用场景，选择部署模型和工具设计模式，并路由到专门的技能。                                                   |
| `build-mcp-app`    | 添加在聊天中内联渲染的交互式 UI 组件（表单、选择器、仪表板）。                                                           |
| `build-mcpb`       | 将本地 stdio 服务器与其运行时打包，用户无需 Node 或 Python 即可安装。                                                   |

每个技能都附带一个 `SKILL.md` 文件以及一个 `references/` 文件夹，其中包含辅助
材料（认证流程、工具设计模式、组件模板、清单 schema），代理会按需读取这些内容。
这些文件采用开放格式，并可与任何实现了该标准的代理配合使用。例如，要在 Claude
Code 中安装它们：

```bash
/plugin marketplace add anthropics/claude-plugins-official
/plugin install mcp-server-dev
```

对于其他代理，请查看你的技能或扩展目录，或者将
[技能目录](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/mcp-server-dev/skills)
（`SKILL.md` 加上 `references/`）克隆到你的代理技能所在位置。

## 开始构建

安装好这些技能后，请让你的代理帮助你构建一个 MCP 服务器。入口技能会在自然语言请求上触发，或者你也可以使用代理的技能调用语法直接调用它。

该技能在编写任何代码之前会先进行一个简短的发现阶段。预计会被问到以下问题：

- **它连接到什么**——云 API、本地进程、文件系统、硬件
- **谁会使用它**——只有你、你的团队，还是任何安装它的人
- **操作范围大小**——少量操作，还是封装一个大型 API
- **用户交互需求**——纯文本结果还是丰富的 UI 组件
- **上游认证**——API 密钥、OAuth 2.0，还是不需要

如果你的开场消息已经涵盖了这些内容，代理就会直接跳到推荐阶段。

## 部署路径

基于发现结果，技能会推荐以下四种路径之一，并相应地搭建脚手架：

**远程 [Streamable HTTP](/specification/2025-03-26/basic/transports#streamable-http)**  
是包装云 API 的默认选择。无需安装，部署一次即可服务所有用户，并且 OAuth 流程可以正常工作，因为服务器能够处理重定向和令牌存储。参考技能包含适用于 Cloudflare Workers 以及可移植 Express/FastMCP 配置的脚手架。

**[MCP 应用](/extensions/apps/overview)** 会通过聊天中渲染的交互式小组件扩展服务器，例如可搜索的选择器、图表和实时仪表盘。当纯文本输出不合适时，技能会转交给 `build-mcp-app`。

**[MCP Bundles (MCPB)](https://github.com/modelcontextprotocol/mcpb)** 将本地服务器及其运行时打包为一个单独的 `.mcpb` 归档文件，因此用户无需配置 Node 或 Python 即可安装它。当服务器必须访问用户机器时使用此路径：读取本地文件、控制桌面应用，或与 localhost 服务通信。技能会转交给 `build-mcpb`。

**本地 [stdio](/specification/2025-03-26/basic/transports#stdio)** 仍可用于原型开发，并且在你准备发布时，有明确的升级路径到 MCPB。
