---
title: 什么是模型上下文协议（MCP）？
sidebarTitle: 什么是 MCP？
---

MCP（模型上下文协议）是一种用于将 AI 应用连接到外部系统的开源标准。

使用 MCP，Claude 或 ChatGPT 之类的 AI 应用可以连接到数据源（例如本地文件、数据库）、工具（例如搜索引擎、计算器）和工作流（例如专用提示词）——使它们能够访问关键信息并执行任务。

可以把 MCP 想象成 AI 应用的 USB-C 接口。就像 USB-C 提供了一种连接电子设备的标准化方式一样，MCP 提供了一种将 AI 应用连接到外部系统的标准化方式。

## MCP 可以实现什么？

- 代理可以访问你的 Google Calendar 和 Notion，充当更个性化的 AI 助手。
- Claude Code 可以使用 Figma 设计生成整个 Web 应用。
- 企业聊天机器人可以连接到组织内的多个数据库，让用户能够通过聊天分析数据。
- AI 模型可以在 Blender 上创建 3D 设计，并使用 3D 打印机将其打印出来。

## 为什么 MCP 很重要？

根据你在生态系统中的位置不同，MCP 可以带来一系列好处。

- **开发者**：在构建或集成 AI 应用或智能体时，MCP 可以减少开发时间和复杂度。
- **AI 应用或智能体**：MCP 可接入由数据源、工具和应用组成的生态系统，从而增强能力并改善最终用户体验。
- **最终用户**：MCP 能让 AI 应用或智能体具备更强的能力，在必要时可以访问你的数据并代表你执行操作。

## 广泛的生态系统支持

MCP 是一种开放协议，得到广泛的客户端和服务器支持。像 [Claude](https://claude.com/docs/connectors/building) 和 [ChatGPT](https://developers.openai.com/api/docs/mcp/) 这样的 AI 助手，像 [Visual Studio Code](https://code.visualstudio.com/docs/copilot/chat/mcp-servers)、[Cursor](https://cursor.com/docs/context/mcp)、[MCPJam](https://docs.mcpjam.com/getting-started) 这样的开发工具，以及许多其他工具都支持 MCP——这让你可以轻松实现一次构建，处处集成。
