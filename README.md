# 模型上下文协议 (MCP)

_刚刚听说 MCP，不知道从哪里开始？查看我们的[文档网站](https://modelcontextprotocol.io)._
该存储库包含：
- MCP规范
- MCP协议架构
- MCP 官方文档
该模式首先是[在 TypeScript 中定义](schema/2026-07-28/schema.ts)，但是
[也以 JSON 模式提供](schema/2026-07-28/schema.json)，适用于更广泛的
兼容性。

官方 MCP 文档是使用 Mintlify 构建的，可在以下位置获取：

[modelcontextprotocol.io](https://modelcontextprotocol.io)。

## 贡献

通过[工作组](https://modelcontextprotocol.io/community/working-interest-groups) 做出贡献
和问题：
- **对规范的更改**在相关工作组中讨论并批准
  在拉取请求或 [SEP](https://modelcontextprotocol.io/community/sep-guidelines) 打开之前。
- **拉取请求** 只能由 `modelcontextprotocol` GitHub 组织的成员打开。
- **其他人**可以通过以下方式报告错误和问题
  [打开问题](https://github.com/modelcontextprotocol/modelcontextprotocol/issues/new/choose)
  或通过加入工作组来参与。

有关详细信息，请参阅 [CONTRIBUTING.md](./CONTRIBUTING.md)。
