Model Context Protocol 的 Official [Ruby SDK](https://github.com/modelcontextprotocol/ruby-sdk) [Version 1.0.0](https://github.com/modelcontextprotocol/ruby-sdk/releases/tag/v1.0.0) 现已推出。这是 [`mcp` gem](https://rubygems.org/gems/mcp) 的首个稳定版本：公共 API 现已稳定，只有在发布主版本时才会推出破坏性变更，遵循 [VERSIONING.md](https://github.com/modelcontextprotocol/ruby-sdk/blob/main/VERSIONING.md) 中记录的 Semantic Versioning 政策。

伴随此次发布，Ruby SDK 现已满足 [SDK 分级系统](https://modelcontextprotocol.io/community/sdk-tiers) 的所有 Tier 2 要求，相关结果已记录在 [Tier 2 评估](https://github.com/modelcontextprotocol/modelcontextprotocol/issues/3127)中，面向 Tier 1 的开发工作仍在进行。

## 1.0 版本包含的内容

1.0 版本实现了 2025-06-18 和 2025-11-25 的规范修订，并以 100% 的通过率完成了服务器和客户端符合性场景测试。其中包括：

- 支持工具、提示、资源（包括模板和订阅）、补全、日志记录、分页、进度和取消的 MCP 服务器，以及用于采样、elicitation（表单和 URL 模式）和根目录的服务器到客户端请求
- 支持完整 OAuth 流程的 MCP 客户端，包括动态客户端注册、PKCE 和范围处理
- stdio 和 Streamable HTTP 传输；HTTP 传输是标准 Rack 应用，因此可以直接挂载到 Rails 路由或任何兼容 Rack 的框架中

## 从 Tier 3 到 Tier 2

Ruby SDK 于 2026 年 3 月被评估为 [Tier 3](https://github.com/modelcontextprotocol/modelcontextprotocol/issues/2340)。此后：

- 服务器符合性从 83.3% 提升至 100%，且没有基线失败项
- 实现了符合性客户端，并以 100% 的通过率完成客户端场景测试
- 在服务器端和客户端均实现了采样、elicitation 和进度通知
- 发布了 [ROADMAP.md](https://github.com/modelcontextprotocol/ruby-sdk/blob/main/ROADMAP.md) 和 [VERSIONING.md](https://github.com/modelcontextprotocol/ruby-sdk/blob/main/VERSIONING.md)

目前也正在开展相关工作，以支持即将发布的 [2026-07-28 规范版本](/posts/sdk-betas-2026-07-28/)。

## 开始使用

安装 gem：

```console
$ gem install mcp
```

一个最小化的 stdio 服务器如下所示：

```ruby
require "mcp"

class ExampleTool < MCP::Tool
  description "A simple example tool that echoes back its arguments"
  input_schema(
    properties: {
      message: { type: "string" },
    },
    required: ["message"]
  )

  class << self
    def call(message:, server_context:)
      MCP::Tool::Response.new([{
        type: "text",
        text: "Hello from example tool! Message: #{message}",
      }])
    end
  end
end

server = MCP::Server.new(
  name: "example_server",
  tools: [ExampleTool],
)

MCP::Server::Transports::StdioTransport.new(server).open
```

请参阅 [Ruby SDK 文档](https://ruby.sdk.modelcontextprotocol.io)，其中包含构建服务器和客户端的指南，包括 Rails 集成。
